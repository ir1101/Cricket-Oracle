Cricket Oracle

A match-outcome predictor for limited-overs cricket. Ingests ball-by-ball data, engineers innings-state features (run rate trajectory, wickets-in-hand, venue priors), and blends a logistic baseline with a gradient-boosted model. Calibrated probabilities power a chase-difficulty heatmap that updates live ball-by-ball.
